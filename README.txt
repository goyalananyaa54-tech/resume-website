# Ananyaa Goyal — Personal Resume Website

## Files
- `index.html` — website content and sections
- `style.css` — visual design and responsive layout

## Before publishing
1. Open `index.html`.
2. Find `YOUR-EMAIL@example.com` and replace it with the email address you want to make public.
3. Check all education dates, titles and descriptions for accuracy.
4. Save both files.

## Publish with GitHub Pages
1. Open your GitHub repository.
2. Choose **Add file → Upload files**.
3. Upload `index.html` and `style.css` (not the ZIP file).
4. Commit the changes.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main` and folder `/(root)`, then click **Save**.
8. Wait a few minutes and refresh the Pages screen for your live URL.

The website uses Google Fonts, so the font styling requires an internet connection. The site remains readable with fallback fonts if Google Fonts cannot load.
